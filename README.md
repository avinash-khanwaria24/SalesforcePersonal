# SalesforcePersonal

Architecture and design work for Salesforce enterprise programs.

## FreshSource Global — farm-to-table distribution

End-to-end Salesforce architecture for a high-volume, multi-region food distributor (Experience Cloud, B2B Commerce, Service Cloud, Agentforce, MuleSoft, SAP). No org metadata is deployed; this is an architect deliverable.

### Integration system landscape

The integration landscape highlights Salesforce Core Cloud, Experience Cloud with social media logins, every data entry point, and every integration through MuleSoft ESB layers.
