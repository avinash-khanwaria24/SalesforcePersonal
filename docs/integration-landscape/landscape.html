FreshSource Global · Integration architecture

Integration system landscape

Salesforce Core Cloud is the operational hub. Experience Cloud is the digital front door, with Google, Apple, and LinkedIn logins for micro-buyers. Every record has a named data entry point. Every engine of record is reached only through MuleSoft ESB layers.

Four landscape highlights

1 · Core Cloud

Salesforce Core Cloud

Sales + Service + B2B Commerce + Order Management + Agentforce on one Hyperforce org. Parties, contracts, hot orders, cases. Not the financial ledger, not bin inventory, not raw IoT.

2 · Experience Cloud

LWR + social logins

FSG Market (NA / LATAM / EMEA), Grower Network, Corporate Onboarding. Micro-buyers: Google, Apple, LinkedIn OIDC. Staff: Okta SAML. Farms: password after Q&C vetting.

3 · Entry points

26 named doors

Guest apply, social register, corporate self-reg, checkout, tickets, voice/email/messaging, internal consoles, Okta SCIM, and ESB inbound from WMS, SAP, GFSR, IoT, SDPE, DocuSign, tax/pay, PIM.

4 · ESB

All integrations via MuleSoft

Experience APIs → Process APIs (circuit breaker, cache, regional close) → System APIs (SAP, WMS, SDPE, GFSR, IoT). No point-to-point Named Credentials from Apex to engines.

Salesforce Core Cloud

Sales Cloud

Account / Contact / ACR party model. HQ → Cluster → Branch. Master Agreement on Contract. Opportunity for new logo only — not on the 50k/day path.

Service Cloud

Case SoR, Entitlements (2-hour enterprise SLA), Omni-Channel skills + capacity, Knowledge grounding for Agentforce.

B2B Commerce

Three WebStores, Buyer Groups, cart, checkout. Pricing and inventory extensions call Experience APIs — not Apex-to-engine.

Order Management

OrderSummary / FulfillmentOrder after Place Order. Splits follow WMS allocation written back through the ESB.

Platform events

High-volume Order_Submitted__e and CDC on lots/orders. ESB consumes Pub/Sub API. IoT pings never land here.

Connect + Data Cloud

Invoices/payouts virtualized from SAP. Data Cloud holds unified profile and archive. Named Credentials target MuleSoft only.

Experience Cloud — social media logins available

Sites

  • FSG Market — LWR + B2B, chefs and micro-buyers, regional stores.
  • FSG Grower Network — guest apply, then Partner users after Q&C.
  • Corporate Onboarding — domain-validated chef self-registration onto a branch Account.

Who uses which login

  • Micro-buyers: Google, Apple, LinkedIn OIDC + optional password. Registration Handler; enterprise domains rejected.
  • Enterprise chefs: password + MFA, or customer IdP SAML (phase 2). No social buttons.
  • Farms: password after enable-as-partner. No guest User, no social.
  • FSG staff: Okta SAML 2.0 + SCIM into Core Cloud. Not Experience Cloud.

All data entry points

Every create/update of a Core Cloud record has a named door. Machine paths enter only through the ESB.

A · Experience Cloud

E1 guest farm apply. E2 social/password micro-register. E3 corporate self-reg. E4 branch delegated admin. E5 checkout. E6 supplier catalog/PO/certs. E7 spoilage ticket. E8 authenticated chat.

B · Service channels

E9 voice (PSTN / Amazon Connect / Salesforce Voice). E10 Email-to-Case. E11 WhatsApp / SMS / Enhanced Messaging. Always a Case. Agentforce first; Omni overflow.

C · Internal consoles

E12 sell Master Agreement. E13 Q&C inspection. E14 merchandiser publish. E15 fulfillment director re-allocate. E16 agent Case work. Okta SSO only.

D · Identity plane

E17 Okta SCIM joiner-mover-leaver (not ESB). E18 social OIDC JIT + ThirdPartyAccountLink. JIT SAML for staff is forbidden.

E · ESB inbound

E19 WMS allocation/ATP. E20 SAP invoice/payout/rebate. E21 GFSR lot status. E22 IoT excursion. E23 SDPE snapshot. E24 DocuSign. E25 tax/pay. E26 PIM catalog.

Closed doors

No guest Case create. No guest pricing. No browser callout to SAP/SDPE/WMS/GFSR. No raw IoT rows. No point-to-point Apex.

Experience APIs

xp-checkout-pricing · xp-buyer-portal · xp-agent-assist · xp-supplier-portal. The only URLs Salesforce Named Credentials are allowed to call.

Process APIs

Pricing circuit breaker + Redis + snapshot. Order allocate/split/PO fan-out. Traceability. Regional EOD ERP close. Cold-chain exceptions. Catalog/tax/pay master.

System APIs

One API per engine: SAP, WMS, SDPE, GFSR, IoT, DocuSign, tax/pay, PIM, plus sys-salesforce (Composite, Bulk 2.0, Pub/Sub). Secrets never leave Anypoint.
